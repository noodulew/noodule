# Disclaimer

Nodule is a personal learning experiment, not a replacement for Geode
and not an attempt to compete with it. Please do not use this project
as an excuse to criticize Geode or its team.

Geode is a large community project built with significant effort,
care, and volunteer time. Slow updates or missing features are normal
for a project of that scale. The team is putting in serious work and
deserves respect and patience.

Nodule exists only to understand how mod loaders work under the hood.
Support Geode and its contributors.
