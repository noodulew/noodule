## Note
Nodule is a personal learning experiment, **not a replacement for Geode** and not an attempt to compete with it. Please do not use this project as an excuse to criticize Geode or its team. Geode is a large community project built with significant effort, care, and volunteer time. Slow updates or missing features are normal for a project of that scale. The team is putting in serious work and deserves respect and patience. This project exists only to understand how mod loaders work under the hood. Support Geode and its contributors.

## Why Nodule?

This project exists purely for educational purposes. It is an attempt to build a minimal mod loader from scratch to understand binary injection, function hooking, and patching. It is not intended to be used by anyone else, and it will not be a stable or feature-complete alternative to Geode.

## Status

Early development. No functional code yet. The repository currently contains only this README and a license file.

## Usage

Not applicable yet. This project is not usable at this stage.

## Planned language

Undecided between C++ and Rust. C++ is the more direct path since Geometry Dash is written in C++. Rust is possible but requires additional setup for interfacing with the game's internals.
